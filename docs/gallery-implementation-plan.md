# 미니멀 발행 갤러리

사용자 요청: 첨부한 포트폴리오처럼 사진과 제목만으로 호를 탐색한다. 기존 nav 디자인을 보존한다.

1. 완료 — 참고 이미지 분석. 3열, 큰 사진, 12px 모서리, 일정한 간격, 흰 제목의 하단 오버레이를 기준으로 한다.
2. 완료 — 5개 테마 예시 호와 6개 실제 원문 커버 이미지. 1차 출처, 방어 중심 보안, 예시 호 표시.
3. 완료 — 전체 발행 호를 표시하는 반응형 갤러리, 간결한 주제/검색 도구, URL로 보존되는 필터. 읽기 페이지에 목록 복귀와 다음 호 탐색 유지.
4. 완료 — 실제 브라우저로 검색·필터·읽기·스크랩·키보드·모바일 검증, 테스트/빌드, 독립 시각 검토.

변경 소유: root는 페이지·스키마·스타일·통합 검증, gallery_content는 새 JSON 및 출처 문서, source_images는 실제 원문 자산, source_cover_routine은 원문 커버 추출을 담당했다. 기존 자동 발행·구독·제휴 기능을 보존한다. 새 의존성 없음. 이미지 교체·검증 후 현재 작업 브랜치에 커밋·푸시한다(사용자 명시 요청).

추가 완료 — 생성 커버를 프로젝트에서 제거, 실제 원문 그림/도표 사용과 출처 표시. 자동 편집에도 원문 이미지 추출을 연결한다.

최종 검증: 21개 편집 테스트, 6개 사이트 계약 테스트, 667개 실제 브라우저 검사, 4개 접근성 프로필 100. 독립 코드·출처 검토와 시각 검토 모두 PASS.
