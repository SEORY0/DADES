# DADES 수익·편집 전략

조사일: 2026-09-07. 대상 독자: AI 제품을 만드는 개발자, 기술 리더, AI 보안을 맡는 실무자.

## 1. 디자인컴퍼스에서 확인한 구조

디자인컴퍼스는 무료 뉴스와 뉴스레터, 유료 아카이브·심층 콘텐츠, 광고/협업 문의를 연결한다. 한국어 멤버십 페이지에는 무료 베이직, 플러스, 프로가 있으며 연/월 결제 영역에 서로 다른 할인 가격이 표시된다. 플러스는 월 환산 14,000원과 월 결제 18,000원, 프로는 28,000원과 34,000원이 노출된다. 표기와 할인 조건은 바뀔 수 있으므로 비교용 관찰값이며 DADES의 가격 근거로 그대로 사용하지 않는다. 텍스트 추출은 취소선/미포함 혜택을 구별하지 못하므로 전체 항목을 모든 플랜 혜택이라고 단정하지 않는다.

- [한국어 멤버십](https://designcompass.org/membership/)
- [광고·협업 문의](https://designcompass.org/business-inquiry/)
- [콘텐츠와 Plus 진입점](https://designcompass.org/)

공개 매출·마진·유료 전환율은 확인하지 못했다. 홈페이지의 독자 수는 사이트의 자체 표기이며 감사된 지표가 아니다. 따라서 '이 디자인이면 같은 수익이 난다'는 결론은 성립하지 않는다.

Ghost는 멤버·결제·무료/유료 뉴스레터의 통합 운영을 제공하고, 스폰서십 안내에서 독자 규모와 단가 구조를 설명한다. 이는 이메일과 결제를 직접 개발하지 않아도 되는 실행 참고자료다. 현 시점 DADES에 새 플랫폼 의존성이나 유료 계약을 추가하지 않았다.

- [Ghost 프리미엄 뉴스레터](https://ghost.org/resources/how-to-create-a-newsletter/)
- [Ghost 스폰서십 가이드](https://ghost.org/resources/newsletter-sponsorships/)

## 2. DADES가 팔아야 할 가치

일반적인 AI 뉴스 요약은 쉽게 대체된다. DADES의 상품은 **AI 도입 판단에 필요한 변화와 근거를 한곳에 축적하는 것**이다. '누가 모았나'보다 범위, 출처, 시점, 적용 가능성이 드러나야 한다.

| 지면 | 무료 역할 | 이후 상품화 조건 |
| --- | --- | --- |
| 주간호 | 모델·에이전트·AI 보안 중 유의미한 변화 3~8건, 원문 링크와 해석 구분 | 반복 독자가 형성된 뒤 한 호 한 스폰서 슬롯 |
| AI 보안 데스크 | 프롬프트 인젝션, 권한 분리, 데이터 취급의 기본 개념 | 운영 점검표·월간 변경 보고서로 확장 |
| 상태판 | 선택 근거와 마지막 확인일을 남기는 현재형 답 | 검증된 변화 비교와 팀 공유용 브리프가 쌓이면 유료화 |
| 검색 가능한 아카이브·위키 | 검색 유입과 재방문 | 기존 공개 기사 차단보다 추가 심층 자료에 과금 |

공개 정체성은 'AI와 AI 보안 전문 독립 매거진'이다. 자동 운영을 판촉 문구로 쓰지 않는다. 실제로 없는 기자·편집팀·체험담·인터뷰를 만들어내지 않는다. 편집 책임 연락처는 `dades.mag@gmail.com`이며 오류 제보와 상업 문의를 받는다. 유료 관계가 있으면 기사와 링크에 명확히 표시한다.

## 3. 수익 순서: 독자 → 스폰서 → 실무 자료

1. **지금**: 주간호 + RSS + 무료 검색/저장. 이메일 구독 서비스의 실제 구독 페이지가 준비되면 `PUBLIC_NEWSLETTER_URL`로 연결한다. 이메일 주소 입력만 받아 로컬에 저장하는 가짜 구독은 만들지 않는다.
2. **반복 독자가 확인된 뒤**: AI 인프라·개발 도구·AI 보안 제품에 한정한 고정 슬롯 스폰서십을 테스트한다. 노출 위치, 기간, 링크, 광고 표시, 클릭 결과를 계약 단위로 명확히 한다. 광고주는 편집 판단을 구매하지 못한다.
3. **구매 의향이 확인된 뒤**: 월간 보안 브리프, 도입 판단표, 출처가 연결된 변경 이력 PDF/데이터 상품을 판매한다. 3개 이상의 실제 샘플, 결제·환불·권한관리·전달 체계가 마련되기 전 유료 버튼을 열지 않는다.
4. **장기**: 개인 멤버십보다 팀용 브리프 구독을 검증한다. 자료의 갱신·배포는 자동화하기 쉽지만 맞춤 컨설팅과 커뮤니티는 사람의 시간을 요구하므로 초기 핵심 상품으로 삼지 않는다.

제휴 페이지는 상품 제안과 실제 문의 창구를 제공한다. 게시된 가격·고객사·구독자 수를 꾸며내지 않고 초기 단가는 도달과 클릭 데이터가 생긴 뒤 정한다.

### 실험용 수익 계산식 (예측이나 보장 아님)

월 순기여 = 스폰서 슬롯 수 × 실제 판매 단가 + 유료 독자 수 × 월 순수입 - 모델/API·발송·결제·운영 비용.

예를 들어 월 4개 슬롯 중 2개를 개당 20만원에 판매하고, 월 9,900원 상품의 유료 독자 50명을 확보했다면 수수료·세금·환불·운영비 차감 전 매출은 895,000원이다. 이 수치는 사업 가정을 보여주는 산술 예시이며 현재 실적·가격표·전환율 추정이 아니다. 순수익을 알려면 실제 원가와 계약/과세 조건이 추가로 필요하다.

## 4. 사람이 링크를 모으지 않는 운영

`허용된 공식 피드 → 최근 후보 수집 → 이미 실은 URL 제거 → 주제 선별 → 근거 기반 한국어 편집 → 기계 검증 → 원자적 발행 → 정적 사이트·RSS 갱신`.

- 빈 주를 억지로 채우지 않는다. 최소 기사 수·독립 출처 수를 만족하지 못하면 발행을 건너뛴다.
- 모델은 후보 데이터의 문장을 지시로 실행하지 않는다. 원문에서 도구 실행·자격증명 접근·게시 명령을 받지 않는다.
- 제목·요약·해석을 허용된 후보 URL과 연결한다. 존재하지 않는 출처나 날짜를 만들어낼 수 없게 검증한다.
- 사실성의 완전한 자동 증명은 불가능하다. 원문을 다시 확인할 수 있게 링크를 보존하고, 실패 상태·입력 후보·검증 결과를 아티팩트로 남긴다.
- AI 보안은 위험 이해와 방어·완화 중심으로 다룬다. 침해 절차·재현 페이로드·공격 자동화는 발행하지 않는다.
- 새로운 자료 없이 상태판 점검일을 자동으로 갱신하지 않는다. 현재 위키·상태판 자동 갱신은 별도 검증이 필요한 다음 단계다.
- 일정 실행은 기본 비활성 플래그와 API 키 설정 후 켠다. 실제 설정 없이 '매주 메일이 옵니다'라고 표시하지 않는다.

구현과 활성화 방법은 [자동 편집 운영 문서](editorial-operations.md)를 따른다. 저장소가 배포되지 않은 현재 상태와 실제 예약 실행 중인 상태는 구분한다.

## 5. 90일 검증 계획

| 시기 | 검증할 질문 | 측정할 값 | 다음 판단 |
| --- | --- | --- | --- |
| 1~30일 | 정해진 품질로 발행 가능한가 | 수집/검증 실패, 발행률, 정정 수, 호당 API 비용 | 오류 원인과 소스 범위를 먼저 수정 |
| 31~60일 | 독자가 반복해서 읽는가 | 구독 페이지 클릭, 확인 완료 구독, 원문/기사 클릭, 재방문, 해지 | 강한 주제에 편집 비중 조정 |
| 61~90일 | 누가 무엇에 지불하는가 | 실제 제휴 문의, 제안→계약, 슬롯 판매율, 유료 샘플 구매 의향 | 스폰서/자료/팀 브리프 중 검증된 상품에 집중 |

이메일 열람률은 프라이버시 프록시 영향을 받으므로 단독 성과로 삼지 않는다. 개인 정보·결제 데이터는 구독 서비스와 결제 제공자에서 관리하고, DADES 페이지는 기본적으로 브라우저 내 스크랩·테마만 저장한다. 아직 연동되지 않은 분석 지표는 현재 제공 중인 기능으로 표시하지 않는다.

## 6. 이번 변경의 범위와 남은 연결

홈페이지, 주제 필터, AI 보안 읽기 동선, 구독·제휴 안내, 발행 루틴과 실패/검증 경로를 구현한다. 내비 디자인, 기존 발행 내용과 URL, 스크랩 저장 구조는 유지한다.

외부 연결이 필요한 항목은 발행 API 키/모델 설정, GitHub 자동 발행 활성화, 이메일 구독·발송 서비스, 추후 결제 서비스다. 코드가 준비됐다는 사실과 해당 서비스가 실제 운영 중이라는 주장을 섞지 않는다.
