# AI 모델 상태판 구현 계획

요청: Chartdex의 비교 시각화와 기존 nav의 글래스 재질을 활용해, 뉴스 없이 성능·토큰 가격·생성 속도·사용량을 읽는 상태판을 만든다. nav와 홈은 보존한다.

1. 완료 — Chartdex 실브라우저/소스 분석, 경쟁 리더보드와 공개 데이터 조사.
2. 완료 — 공개 출처 스냅샷, 단위/결측 처리, 갱신 루틴과 실패 보존.
3. 완료 — nav 재질·큰 글자·짧은 설명, 순위·차트·검색·비교·비용 계산. 기존 상태는 브라우저 139개 검사 통과.
4. 완료 — Paper 제거, White·Ink 및 Paper→White 이전. 사이트 테스트17개 및 Chrome 초기 설정/전환 검증 통과.
5. 완료 — 실제 아이콘7종과 유리판 레이어, 모델 ID 매핑 및 갱신·제거. White·Ink의 375/768/1280 화면을 직접 확인.
6. 완료 — 브라우저 511개 검사·74개 캡처, 단위44개·사이트17개, 빌드·TypeScript, 독립 시각/기능 검토 통과. 결과는 docs/status-verification.md, 작업 브랜치 전달 내역은 Git 이력에 기록한다.

소유: status_data는 수집 스크립트/스냅샷/워크플로/데이터 테스트. root는 UI/스키마/시각화/통합 검증. 새 의존성 없음. 이미지 생성 없음. 실시간 관측과 벤치마크 발표 시점을 구분한다.
